# 照片加边框 · Photo Boarder

纯前端的照片加边框工具。原生 HTML / JS / CSS + Canvas 2D 实现，直接双击 `index.html` 即可使用，无需安装、无需联网构建；唯一第三方依赖是本地内置的压缩库 pako（MIT，无网络请求）。网页字体需联网加载，缺失时自动回退系统字体。

## 功能

- **上传照片**（拖拽 / 点击 / 示例图），自动生成白色边框（下边更高）
- **边框比例**：左右 / 上 / 下宽度分别可调
- **双重阴影**：
  - 照片阴影（可开关、强度、角度）
  - 白色底座（开启后强制带卡片投影，突显分层；强度、角度可调）
- **底部信息区（统一内容列表）**：
  - Logo / 参数 / 文本 / 图片全部收进**一个列表**，可拖拽排序、增删，内置预设顺序（Logo → 光圈/快门/ISO/焦距/镜头 → 作者落款）
  - **默认全部同一行排列**；每项有独立「换行」开关，勾选则该项断行
  - 每项独立字体 + 字号（图片项为独立大小），超宽时整行等比自动缩小
  - **内容项间距**：全局滑块控制项与项之间的空隙（同行=水平间距，断行=垂直行距）
  - **与照片间距**：独立滑块控制底部信息与照片下沿的距离
  - 相机品牌 Logo：内置 Canon / Nikon / Sony / FUJIFILM / LEICA / Panasonic / LUMIX / OLYMPUS / OM SYSTEM，支持自定义 Logo 上传、大小与颜色
  - 参数类型：光圈 / 快门 / ISO / 焦距 / **镜头** / 自定义
- **EXIF 自动填参**：上传照片时自动读取拍摄参数（光圈 / 快门 / ISO / 焦距 / 镜头名）。会覆盖仍为默认值 / 空值 / 之前由 EXIF 自动填充 / 刚从配置文件导入的参数项（导入配置是一次性模板设置，之后每张新照片都会套用各自的 EXIF），但不覆盖用户手动输入的内容
- **导出**：PNG / JPG（带质量滑块）
- **作品保存 / 恢复**：导出 `.boarderconf`（见下）

## .boarderconf 作品格式

`.boarderconf` 本质是一个 **标准 ZIP 压缩文件**（可用 `unzip` / 归档实用工具直接打开），结构如下：

```
settings.json              # 版本 3 的完整设置，图片以相对路径引用
images/logo.png            # 自定义 Logo（如有），扩展名随真实格式
images/imgi4.jpg           # 内容列表里的图片（每张一个文件，扩展名随格式）
```

导出时打包**除主照片外**的全部内容（自定义 Logo、内容列表里的图片 + 完整设置）；导入时还原设置与图片。图片文件的扩展名按**真实字节格式**判定（PNG / JPG / GIF / WebP / BMP / **SVG** / HEIC / HEIF / AVIF 等），因此上传 SVG 格式的 Logo 也能原样保存并在导入后还原；导入时据此恢复正确的 MIME 类型来解码。**旧版设置仍可直接导入**：v1 纯 JSON（图片 base64 内嵌）、v2 `.boarderconf`（logo + 参数 + 文本三区块）都会自动转成统一内容列表。

压缩使用 **pako**（MIT，纯 JS 的 zlib 移植，见 `pako.min.js`），DEFLATE 动态哈夫曼 + LZ77，压缩率与速度远高于手写实现；`zip.js` 负责 ZIP 容器组装/解析（也内置了备用编解码器，若 pako 未加载会自动回退）。

## 文件

- `index.html` — 界面
- `style.css` — 样式
- `app.js` — 核心逻辑（Canvas 渲染、统一内容列表、拖拽、导入导出）
- `exif.js` — 极简 JPEG EXIF 读取（零依赖），用于自动填参
- `zip.js` — ZIP 容器打包 / 解析
- `pako.min.js` — DEFLATE 压缩（MIT，开源 zlib 移植）
- `brand_paths.js` — 品牌 Logo 矢量路径（Simple Icons，CC0）
